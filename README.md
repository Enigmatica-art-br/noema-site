# Case 27: Noema — site oficial

Repositório do site oficial de Case 27: Noema. A versão pública é incorporada pela central Enigmática Games em `games.enigmatica.art.br/noema/`.

As imagens ficam em `assets/images/`. Os botões da Steam levam para https://store.steampowered.com/app/5361160.

O site tem versões em português (Brasil) e inglês. Os textos ficam em `assets/noema-i18n.js` e a troca é feita por `assets/i18n.js`.

Mantenha `noema/` e `assets/` sincronizados com o repositório `games`, que é o que vai ao ar.
